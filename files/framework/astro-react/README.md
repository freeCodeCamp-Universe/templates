This boilerplate is meant to be bootstrapped using the universe CLI tool. It's a template to create curriculum style sites.

After creating a project, you can run it by...

- installing dependencies with `pnpm  i`
- run `pnpm dev` to start the dev server

- Go to the URL and go through the lesson to see the different lesson types
- Change the content in `src/content/curriculum/english.md` to create your own lessons.
